# AIニュースまとめ

日本語のAIニュースを、毎朝6時（日本時間）に自動で集めて、見やすいWebページとして公開するしくみです。
お金はかかりません（GitHubの無料の機能だけで動きます）。

載せるのは、記事ごとに「タイトル・公開日・サイト名・冒頭の短い説明（100文字ほど）・元記事へのリンク」だけです。
記事の本文はのせません。くわしくは、必ず元記事を読んでください。

---

## 1. どんなしくみ？

1. 毎朝6時に、GitHubの無料のタイマー機能（**GitHub Actions**）が自動で動きます。
2. ニュースサイトが配っている「新着記事の一覧」（**RSS**）を読み取ります。
3. AIに関係する記事だけを選び、3つの分野（チャット・コード／画像づくり／動画づくり）と「未分類」に分けます。
4. 記事のタイトルや説明にサービス名があれば、そのサービスの料金の色（無料・無料プランあり・有料のみ）を付けます。
5. 公開から14日たった記事は消えます。1つの分野に出るのは、新しい順に最大8件です。
6. できたページを、GitHubの無料の公開機能（**GitHub Pages**）で公開します。

使っているニュースサイト（RSSの一覧）は、`data/sources.json` に書いてあります。

---

## 2. 自分のパソコンで動かして確認する

**やること：記事を集めて、ページ（`index.html`）を作る。**

1. このフォルダ（`AIニュースまとめ`）を、エクスプローラーで開きます。
2. フォルダ内の何もないところで、**Shiftキーを押しながら右クリック**して、「PowerShell ウィンドウをここで開く」（または「ターミナルで開く」）を選びます。
3. 次のコマンドを入力して、Enterキーを押します。

```
python scripts/build.py
```

- このコマンドは、「RSSを読んで、記事を選んで、`index.html` を作る」という意味です。
- `scripts/build.py` は、そのための小さなプログラムのファイルです（このフォルダに実際にあります）。
- 「記事 ◯ 件で index.html を作りました。」と出れば成功です。
- 「読めなかったサイト: …」と出たときは、そのサイトの一覧が一時的に読めなかっただけのことが多いです。次の日に自動で直ります。

4. フォルダにできた `index.html` を、**ダブルクリック**で開きます。ブラウザでページが表示されます。

## 3. サービスを足す・直す方法（`data/services.json`）

**このファイルは何？** サービスの名前・料金の色・一言説明を書いた一覧です。**あなたが手で直せます。**
記事のタイトルや説明に、ここに書いたサービス名が出てくると、その記事に料金の色が付きます。

**直し方：** `data/services.json` を、メモ帳などで開いて、書き換えて保存します。

サービス1つ分の書き方（**下は説明用の例です。そのままコピーしないでください**）:

```
  {"name": "サービスの名前", "aliases": ["別の呼び名"], "category": "chat", "price": "mid", "icon": "💬", "desc": "ひとこと説明"},
```

| 項目 | 意味 |
|---|---|
| `name` | サービスの名前。記事の中から、この名前を探します |
| `aliases` | 別の呼び名（省略できます）。例: Canva のAI機能 → `"Canva"` |
| `category` | 分野。`chat`（チャット・コード）、`image`（画像づくり）、`video`（動画づくり）のどれか |
| `price` | 料金の色。`free`（無料）、`mid`（無料プランあり）、`paid`（有料のみ） |
| `icon` | カードに出る絵文字 |
| `desc` | ひとこと説明 |

**書き間違いを防ぐコツ：**
- 1つ分は `{` で始まり `}` で終わります。次のサービスとの間には、カンマ `,` が必要です。
- ただし、**最後のサービスのうしろにはカンマを付けません**。
- 文字を囲む `"` を、消さないでください。
- 直したあとは、手順2のコマンドを実行します。書き間違いがあると、「`data/services.json` を読めませんでした」と、場所を教えてくれます。

### 料金の色は、必ず確認してください

**最初に入っている料金の色は、サンプルページの仮の値です。** 実際の料金とちがうことがあります。
各サービスの公式サイトで「料金」のページを見て、今の料金に合わせて `price` を直してください。
料金は変わることがあるので、ときどき見直すと安心です。

## 4. 記事の元になるサイトを足す方法（`data/sources.json`）

**このファイルは何？** 記事を集めるサイト（RSS）の一覧です。

サイト1つ分の書き方（**下は説明用の例です**）:

```
  {"name": "サイトの名前", "url": "https://example.com/rss.xml", "ai_only": false},
```

| 項目 | 意味 |
|---|---|
| `name` | ページに出るサイト名 |
| `url` | そのサイトのRSSのアドレス |
| `ai_only` | `true`＝AIの話題だけのサイト（記事を全部のせる）／`false`＝いろいろな話題のサイト（AIの記事だけ選ぶ） |

**足す前に必ず確認してください：**
- そのサイトのRSSの利用条件（「RSSのご利用について」など）を読みます。禁止されていないか確認してください。
- RSSのアドレスは、ブラウザで開いて、文字がずらっと出ることで確認できます。

## 5. 「保存」機能と、バックアップ

気になった記事は、カードの「☆ 保存」で保存できます。保存した記事は、14日たっても消えません。

**大事な注意：**
- 保存した記事は、**あなたが使っているブラウザの中だけ**に残ります。ほかのパソコンやスマホとは共有されません。
- ブラウザの「閲覧データを消す」を実行したり、シークレットモードで使ったりすると、**保存が消えることがあります**。

**消えたときのために、バックアップを取ってください：**
1. ページの一番下の「保存した記事のバックアップを書き出す」を押します。
2. `ai-matome-backup-年月日.json` というファイルがダウンロードされます。大切な場所に置いてください。
3. 保存が消えたときは、「バックアップを読み込む」を押して、そのファイルを選べば元に戻ります。

保存した記事があるのに、7日以上バックアップを取っていないときは、ページに「バックアップを取りましょう」と出ます。

## 6. 自動更新が止まったときに気づく方法

**① GitHubからのお知らせメール（いちばん簡単）**
自動実行が失敗すると、GitHubが登録したメールアドレスにお知らせを送ります（初期設定）。次の場所で、届く設定になっているか確認できます。
- GitHubの右上のアイコン →「Settings」→ 左の「Notifications」→「System」の中の「Actions」。
- 「Send notifications for failed workflows only」にチェックが入っていれば、失敗したときだけメールが届きます。

4つのサイトの**すべて**のRSSが読めなかった日は、わざと「失敗」にしてあるので、このメールが届きます。
1つのサイトだけ読めなかった日は、ほかのサイトの記事で続けます（メールは届きません）。

**② 自分で確認する**
GitHubのリポジトリの画面で、上の「Actions」を押すと、毎日の実行の一覧が出ます。緑のチェックは成功、赤い×は失敗です。

**③ 手で動かす**
「Actions」→ 左の「毎日の更新」→ 右の「Run workflow」→ 緑の「Run workflow」ボタン。

**④ 止まってしまったとき**
GitHubは、リポジトリに60日間まったく動きがないと、自動実行を止めることがあります。
このしくみは毎日記事を保存するので、通常は止まりません。もし止まったら、「Actions」の画面に出る「Enable workflow」を押してください。

## 7. ITmedia AI＋について（利用条件の注意）

ITmedia の「RSSのご利用条件」には、「記事の一部だけの抜き出しや改変の禁止」「アプリなどへの組み込みは事前に問い合わせ」といった内容があります。
このページは、**問い合わせをしないで使う**と決めて、ITmedia AI＋を入れています。
もし ITmedia から「条件に反している」と言われたときは、`data/sources.json` から ITmedia AI＋の1つ分（`{` から `}` まで）を消して、ご対応ください。

そのほかのサイト（GIGAZINE、ASCII.jp、Publickey）は、RSSの利用条件が見つかりませんでした。サイト側から連絡があれば、同じように対応してください。

## 8. よくあるつまずき

- **「python が見つかりません」と出る：** Pythonが入っていません。https://www.python.org/downloads/ からダウンロードし、インストールのとき「Add python.exe to PATH」にチェックを入れてください。
- **記事が少ない・「未分類」ばかり：** サービス一覧に載っていないサービスの記事は「未分類」になります。よく出てくるサービスがあれば、手順3で足してください。
- **分野が合っていない：** `data/services.json` の `category` を直してください。
- **料金の色が付かない記事がある：** タイトルか説明にサービス名が出てこない記事は、灰色（色なし）です。仕様です。
- **ページに記事が出ない日がある：** 画像づくり・動画づくりは、記事が少ない日は0件になることがあります。
